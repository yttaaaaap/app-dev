## Overview
**Spider-Man: Into the Spider-Verse** is an acclaimed animated superhero film that introduces Brooklyn teenager **Miles Morales**, who becomes the new Spider-Man and joins other Spider-Heroes from parallel dimensions to stop a threat to all reality.
